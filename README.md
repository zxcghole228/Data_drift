# Data Drift Guardian

Учебный проект системы проверки качества табличных данных и обнаружения сдвигов распределений.

## Текущее состояние

Подготовлен стартовый каркас: структура Python-пакета, объявления интерфейсов, пример конфигурации, распределение ответственности и два недельных плана. Статистические методы, проверки, ML-модуль и генератор данных ещё не реализованы: их заглушки явно вызывают `NotImplementedError`. Notebook является шаблоном, а Streamlit показывает стартовую страницу. Фактических результатов экспериментов пока нет.

Цель первой недели — первый совместный проход данных через систему и проверка основных модулей. Это промежуточный результат, а не финальная сдача.

## Что должно быть в итоговом решении

- Загрузка CSV/Parquet и проверка схемы.
- Контроль типов, пропусков, дубликатов и диапазонов.
- KS-тест, Wasserstein, χ², PSI и Jensen–Shannon Divergence.
- Adversarial Validation на LightGBM с ROC-AUC на отложенных данных и важностями признаков.
- Единый интерфейс `analyze(reference, current, config) -> dict`.
- Streamlit-дашборд, графики распределений и объяснимые алерты.
- Воспроизводимый генератор демонстрационных данных, notebook и unit-тесты.
- Итоговый HTML- или PDF-отчёт, Dockerfile, инструкция запуска и скринкаст 2–5 минут.

Описание возможностей и ограничений: [docs/architecture.md](docs/architecture.md).

## Подготовка окружения

Для общей среды команды выбран Python 3.12; пакет ограничивает поддерживаемую ветку диапазоном `>=3.12,<3.13`. Зафиксированный процесс проверки: [docs/environment.md](docs/environment.md).

```bash
python -m venv .venv
```

Активация в Linux/macOS:

```bash
source .venv/bin/activate
```

Активация в Git Bash на Windows:

```bash
source .venv/Scripts/activate
```

Активация в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установка зависимостей в активированное окружение:

```bash
python -m pip install -e ".[dev]"
```

В `pyproject.toml` задан стартовый набор зависимостей. Проверенный набор точных версий нужно зафиксировать после согласования окружения 07.09. Полная установка и Docker-сборка в рамках подготовки каркаса не проверялись.

## Запуск каркаса

```bash
python -m streamlit run app/streamlit_app.py
```

Сейчас откроется только стартовая страница. Анализ таблиц появится по мере реализации модулей.

Будущий API, пока не исполняемый сценарий анализа:

```python
from data_drift_guardian import analyze

# reference и current — pandas.DataFrame.
# В текущем каркасе вызов завершится NotImplementedError.
result = analyze(reference, current, config=config)
```

Описание результата: [docs/contracts.md](docs/contracts.md).

После добавления содержательных тестов запускать:

```bash
python -m pytest
```

Сейчас тестовых функций нет: `pytest` сообщит об отсутствии собранных тестов. План проверок находится в [tests/README.md](tests/README.md).
