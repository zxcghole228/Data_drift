# Данные

В этой папке хранится инструкция. Исходные и сгенерированные датасеты не коммитятся.

- `generated/`: результаты будущего `scripts/generate_demo_data.py`, создаются локально.
- `raw/`: при необходимости локальные копии внешних данных; источники указываются ссылками.

Стартовая схема синтетического примера: числовые `age`, `income`, категориальный `region`. Генератор пока не реализован. Михаил добавляет команды запуска, типы, размеры, seed и параметры сценариев 07.09.

Для тестов предпочтительны небольшие DataFrame, создаваемые внутри теста. Для тестов файлового чтения данные записываются во временную папку.
