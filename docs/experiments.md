# Эксперименты и калибровка

Документ объединяет демонстрационные наблюдения, методику калибровки и команды
воспроизведения. Источником машинно-читаемых результатов остаются файлы в
`report/experiments/`.

## Демонстрационные сценарии

Генератор создаёт независимые Reference и Current с фиксированным seed:

| Сценарий | Изменение Current |
| --- | --- |
| `none` | распределения не изменяются намеренно |
| `numeric` | `age` увеличивается на 8 лет |
| `categorical` | доля региона `central` растёт с 0.30 до 0.55 |
| `missingness` | пропуски `income` растут с 2% до 8% |
| `combined` | все три изменения одновременно |

Полная демонстрация находится в `notebooks/demo.ipynb`. Она использует
несколько контрольных seed, чтобы контроль без внесённого дрейфа не был копией
Reference и не создавал ложного впечатления, что статистический тест никогда
не ошибается.

## Наблюдения первого прогона

Для Reference `2000`, Current `1200`, `seed=42`, `alpha=0.05` и поправки BH:

| Сценарий | Алертов | age KS q | age W | age PSI | age JS | region χ² q | region PSI | Missing Δ, п.п. | OOF AUC |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `none` | 0 | 0.989324 | 0.3802 | 0.0150 | 0.00270 | 0.989324 | 0.00240 | 0 | 0.49377 |
| `numeric` | 3 | 3.67e-48 | 8.2535 | 0.4560 | 0.07862 | 0.988019 | 0.00240 | 0 | 0.66635 |
| `categorical` | 2 | 0.989324 | 0.3802 | 0.0150 | 0.00270 | 1.38e-34 | 0.22518 | 0 | 0.59996 |
| `missingness` | 2 | 0.989324 | 0.3802 | 0.0150 | 0.00270 | 0.989324 | 0.00240 | 6 | 0.52158 |
| `combined` | 8 | 3.67e-48 | 8.2535 | 0.4560 | 0.07862 | 6.91e-35 | 0.22518 | 6 | 0.72612 |

Один из пяти независимых контрольных seed дал статистические алерты. Это
ожидаемая возможность при проверке гипотез, а не ошибка реализации. BH снижает
ожидаемую долю ложных открытий, но не гарантирует зелёный результат каждого
контрольного запуска.

Основные выводы:

- сдвиг `age` обнаруживают KS, PSI и JS, а Wasserstein показывает величину в
  годах;
- изменение `region` обнаруживают χ² и PSI;
- рост пропусков выявляет Data Quality, поскольку drift-метрики исключают NaN;
- Adversarial ROC-AUC превышает demo-порог в комбинированном сценарии;
- ни один сигнал без фактического target не доказывает concept drift.

## Калибровочная сетка

Runner вызывает только публичный `analyze` и не содержит отдельной реализации
метрик. Полный запуск:

```bash
python scripts/run_calibration.py
```

По умолчанию выполняются 20 seed для каждого сочетания:

- Current: `500`, `1200` и `3000` строк;
- Reference: `5000` строк;
- контроль без внесённого дрейфа;
- сдвиг `age`: `2`, `4` и `8` лет;
- пропуски `income`: `4%`, `8%` и `15%` при `2%` в Reference;
- категориальный и комбинированный сценарии.

Итого: 27 случаев, 540 вызовов `analyze`, включая 60 контролей. Зафиксированный
полный прогон создал 18 900 строк отдельных решений и 945 строк сводки.

Быстрый smoke без тяжёлого ML-блока:

```bash
python scripts/run_calibration.py \
  --seeds 3 7 \
  --current-sizes 500 \
  --age-shifts 2 8 \
  --missing-fractions 0.04 0.15 \
  --n-reference 1000 \
  --disable-adversarial \
  --output-dir outputs/calibration-smoke \
  --overwrite
```

`--disable-adversarial` предназначен только для быстрой проверки runner и не
заменяет полный эксперимент.

## Артефакты

| Файл | Содержимое |
| --- | --- |
| `report/experiments/calibration_runs.csv` | решение каждого метода в каждом запуске |
| `report/experiments/calibration_summary.csv` | агрегированные значения и доли решений |
| `report/experiments/calibration_metadata.json` | сетка, версии, время, commit/config SHA-256 |

В сводке различаются:

- `false_alert_rate` — алерты в контроле без намеренного дрейфа;
- `detection_rate` — срабатывания метода на целевом для него сдвиге;
- `non_target_alert_rate` — срабатывания проверки вне её целевого сценария.

Решения с `alert=None` не входят в знаменатель `n_decisions`. Двадцать seed
дают инженерную демонстрацию, но не точную production-оценку false-positive
rate. Реальные пороги требуют исторических данных, сезонности, размеров окон и
оценки стоимости ложных и пропущенных тревог.

## Сквозной приёмочный сценарий

```bash
python scripts/generate_demo_data.py \
  --scenario combined \
  --seed 42 \
  --n-reference 5000 \
  --n-current 1200 \
  --format both

python -m data_drift_guardian \
  --reference data/generated/combined/reference.parquet \
  --current data/generated/combined/current.parquet \
  --config configs/demo_calibrated.yaml \
  --json-output outputs/acceptance/combined.json \
  --html-output outputs/acceptance/combined.html \
  --overwrite
```

Зафиксированные ориентиры этого сценария:

- статус `warning`, 9 алертов;
- `age` Wasserstein `8.4384` при feature-пороге `3.0`;
- `region` Cramér's V `0.195349`;
- Adversarial OOF ROC-AUC `0.735718` при demo-пороге `0.70`.

CLI, JSON, HTML и Streamlit должны показывать одинаковые значения
`effective_config`, Data Quality, drift-метрик, ML-результата и алертов.
Форматирование и время выполнения в числовое равенство не входят.

## Ограничения результатов

`configs/demo_calibrated.yaml` предназначен только для синтетической
демонстрации. Полученные пороги не переносятся автоматически на production.
Калибровка на реальном источнике должна учитывать бизнес-риск, сезонность,
обновление Reference и доступность запаздывающего Feedback.
