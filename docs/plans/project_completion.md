# План завершения проекта по коммитам

План заменяет календарное деление задач. Каждый пункт заканчивается отдельным
небольшим коммитом, собственной проверкой и рабочим состоянием ветки. Следующий
коммит начинается только после успешной проверки предыдущего.

Основной контракт online-слоя: [../online_monitoring.md](../online_monitoring.md).

### 2. `feat: add persistent online monitoring state`

## Правило готовности коммита

Коммит считается завершённым, если:

- он решает только заявленную подзадачу;
- новые публичные контракты документированы;
- новые ветви поведения покрыты тестами;
- полный набор тестов не регрессировал;
- временные данные, SQLite, outputs и секреты не попали в Git;
- в сообщении следующему этапу записаны команды и фактические результаты
  проверки.
