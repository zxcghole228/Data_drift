# Числовые методы дрейфа

Модуль `data_drift_guardian.drift.numeric` реализует две независимые метрики
для вещественных числовых признаков. Функции не изменяют входные Series,
исключают `NaN`, `+inf` и `-inf`, а их количество сохраняют в `details`.
Каждой выборке требуется минимум два конечных значения. При меньшем количестве
возвращается `status="skipped"` с причиной.

## KS-test

Двухвыборочный двусторонний критерий Колмогорова–Смирнова проверяет нулевую
гипотезу о том, что независимые Reference и Current получены из одного
непрерывного распределения. Статистика D — максимальное абсолютное расстояние
между эмпирическими функциями распределения.

Малое p-value означает, что наблюдаемая или ещё более сильная разница была бы
редкой при верной нулевой гипотезе. Оно не является вероятностью того, что
дрейф есть или отсутствует. Чувствительность теста растёт с размером выборок.
Для дискретных, сильно округлённых данных и большого числа повторов его
классические предпосылки требуют осторожной интерпретации.

Функция возвращает исходный p-value. Порог `alpha`, поправка на множественные
проверки и итоговый alert относятся к общему pipeline и применяются позже.

## Wasserstein-1

Расстояние Вассерштейна измеряет работу по переносу вероятностной массы между
одномерными распределениями. Результат выражен в единицах самого признака:
например, для возраста — в годах, для дохода — в единицах валюты. Поэтому один
универсальный числовой порог для разных признаков применять нельзя без
нормировки или отдельного обоснования.

У расстояния нет p-value. Пока порог для признака не задан конфигурацией,
успешный расчёт имеет `status="ok"`, но `threshold=None` и `alert=None`.

## Минимальный вызов

```python
import pandas as pd

from data_drift_guardian.drift import ks_test, wasserstein

reference = pd.Series([20.0, 25.0, 30.0, 35.0])
current = pd.Series([30.0, 35.0, 40.0, 45.0])

ks_result = ks_test(reference, current)
wasserstein_result = wasserstein(reference, current)
```

Обе функции возвращают общий `CheckResult`. Размеры и очистка выборок доступны
через `result["details"]`; численное значение — через `result["value"]`.

## Воспроизводимый пример для передачи в pipeline

Для генератора с `seed=42`, `n_reference=5000`, `n_current=3000` получены такие
результаты по `age`:

| Сценарий | KS D | KS p-value | Wasserstein |
| --- | ---: | ---: | ---: |
| `none` | 0.013733 | 0.866786 | 0.3714 года |
| `numeric` (сдвиг +8 лет) | 0.270867 | 1.6534e-121 | 8.3687 года |

Это наблюдение для конкретного seed и размеров, а не универсальная граница
алерта. Минимальный объект для pipeline можно собрать так:

```python
checks = {
    "ks": ks_test(reference["age"], current["age"]),
    "wasserstein": wasserstein(reference["age"], current["age"]),
}
```
