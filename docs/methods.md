# Методы анализа качества и дрейфа

Все проверки вызываются единым pipeline `analyze(reference, current, config)` и
возвращают JSON-безопасные результаты общего формата. Входные DataFrame не
изменяются. Неприменимая проверка получает `status="skipped"` и объяснение,
вычислительная ошибка — `status="error"`.

## Карта методов

| Область | Метод | Что измеряется |
| --- | --- | --- |
| Data Quality | пропуски, дубликаты, Infinity, Min/Max | целостность и пригодность данных |
| Числовой drift | KS-test | статистическая различимость распределений |
| Числовой drift | Wasserstein-1 | расстояние в единицах признака |
| Категориальный drift | χ² и Cramér's V | различие частот и размер эффекта |
| Stability | PSI | логарифмическое изменение долей по общим ячейкам |
| Stability | Jensen–Shannon divergence | симметричное расстояние между распределениями |
| Общий drift | Adversarial Validation | различимость двух батчей моделью LightGBM |

## Подготовка данных

- `NaN`, `None` и `pd.NA` учитываются Data Quality, но исключаются из обычных
  drift-метрик.
- `+inf` и `-inf` считаются критическими нарушениями качества и исключаются из
  числовых распределений.
- Для KS и Wasserstein требуется минимум два конечных значения в каждой
  выборке.
- Количество исходных и использованных наблюдений сохраняется в `details`.
- Для PSI и JS числовые бины строятся только по Reference и затем одинаково
  применяются к Reference и Current.

## KS-test

Двухвыборочный критерий Колмогорова–Смирнова проверяет нулевую гипотезу о том,
что независимые выборки получены из одного непрерывного распределения.
Статистика `D` — максимальное абсолютное расстояние между эмпирическими
функциями распределения.

Малое p-value не является вероятностью наличия дрейфа. Чувствительность теста
растёт с размером выборок, а дискретные и сильно округлённые значения требуют
осторожной интерпретации. Pipeline сохраняет исходный `p_value` и применяет
настроенную поправку на множественные проверки.

## Wasserstein-1

Расстояние Вассерштейна измеряет стоимость переноса вероятностной массы между
одномерными распределениями. Значение выражено в единицах признака: для
возраста — в годах, для дохода — в денежных единицах. Поэтому порог задаётся
отдельно для признака либо обосновывается для конкретной шкалы.

У метрики нет p-value. Если порог не настроен, значение вычисляется, но
`alert=None`: это отсутствие автоматического решения, а не доказательство
стабильности.

## Категориальный χ² и Cramér's V

Критерий независимости Пирсона сравнивает частоты категорий в Reference и
Current:

\[
\chi^2 = \sum_{i,j}\frac{(O_{ij}-E_{ij})^2}{E_{ij}}.
\]

Категории берутся из объединения двух выборок. Значения разных Python-типов не
сливаются. Редкие категории с суммарной частотой меньше `10` объединяются в
одну ячейку. После объединения должны остаться минимум две категории, а
наблюдаемые и ожидаемые частоты должны быть не меньше `5`; иначе проверка
пропускается без выдачи сомнительного асимптотического p-value.

Для успешно проверенной таблицы рассчитывается Cramér's V:

\[
V = \sqrt{\frac{\chi^2}{n\min(r-1,c-1)}}.
\]

Он отражает нормированную силу различия, но сам по себе не создаёт алерт.
Диагностика также сохраняет новые, исчезнувшие и объединённые категории.

## Поправка Benjamini–Hochberg

В одном вызове `analyze` семейство состоит из всех пригодных p-value KS и χ².
Пропущенные и ошибочные проверки в него не входят. При
`multiple_testing: bh` решение принимается по `adjusted_p_value`; поправка
контролирует ожидаемую долю ложных открытий среди отклонённых гипотез, а не
вероятность ошибки каждой отдельной проверки.

## PSI

Для вероятностей Reference \(p_i\) и Current \(q_i\):

\[
\operatorname{PSI}(P,Q)=\sum_i(q_i-p_i)\ln\frac{q_i}{p_i}.
\]

Нулевые вероятности обрабатываются аддитивным сглаживанием
`psi_smoothing`, после чего векторы нормируются. Результат зависит от числа
бинов и сглаживания, поэтому распространённые пороги PSI не являются
универсальными production-границами.

## Jensen–Shannon divergence

Для \(M=(P+Q)/2\):

\[
\operatorname{JSD}(P,Q)=\frac12D_{KL}(P\Vert M)+
\frac12D_{KL}(Q\Vert M).
\]

`scipy.spatial.distance.jensenshannon` возвращает квадратный корень из
divergence, поэтому реализация возводит результат SciPy в квадрат. При
основании логарифма `2` итог находится в диапазоне от `0` до `1`.

Для числовых признаков внутренние границы являются квантилями Reference, а
крайние границы равны `-inf` и `+inf`. Для константного Reference создаются
ячейки ниже, равно и выше эталонного значения. Для категорий используется
объединённое пространство, поэтому новые значения Current не теряются.

## Adversarial Validation

Строки Reference получают служебную метку `0`, Current — `1`. LightGBM
пытается определить источник строки, а ROC-AUC рассчитывается только по
out-of-fold предсказаниям.

Внутри каждого train-fold отдельно обучаются:

- медианная импутация числовых признаков;
- заполнение категориальных пропусков;
- `OneHotEncoder(handle_unknown="ignore")`;
- `LGBMClassifier` с фиксированным seed.

При `group_column: null` используется `StratifiedKFold`, иначе —
`StratifiedGroupKFold`. Group ID автоматически исключается из model features.
ID, target и остальные служебные поля также должны быть перечислены в
`exclude_columns`.

Feature Importance рассчитывается как средняя нормированная gain-важность:
важности one-hot столбцов сначала суммируются до исходного признака, затем
нормируются внутри фолда и усредняются. Они показывают вклад признака в
различение батчей, но не причинный источник изменения.

ROC-AUC около `0.5` означает, что выбранная модель не смогла различить батчи;
это не доказывает отсутствия дрейфа. Высокий ROC-AUC подтверждает различимость
входов, но без фактического target не доказывает падение качества основной
модели.

## Проверенный демонстрационный пример

Для `seed=42`, Reference `5000` строк и Current `3000` строк:

| Сценарий | Признак | KS D | Wasserstein | PSI | JS divergence |
| --- | --- | ---: | ---: | ---: | ---: |
| `none` | `age` | 0.013733 | 0.3714 | 0.002573 | 0.000464 |
| `numeric` | `age` | 0.270867 | 8.3687 | 0.456097 | 0.078878 |
| `none` | `region` | — | — | 0.001071 | 0.000193 |
| `categorical` | `region` | — | — | 0.270713 | 0.048116 |

Эти числа подтверждают воспроизводимость демонстрации, но не задают
универсальные пороги для других данных.

## Интерпретационные границы

Data drift описывает изменение распределения входных признаков. Concept drift
означает изменение связи `P(y|X)` и требует запаздывающих фактических ответов
либо иной оценки качества основной модели. Статистический алерт является
сигналом для расследования, а не автоматическим требованием переобучения.

Подробная структура результатов и разрешение порогов описаны в
[`contracts.md`](contracts.md), фактические запуски — в
[`experiments.md`](experiments.md).
