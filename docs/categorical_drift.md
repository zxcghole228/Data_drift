# Категориальный χ²-тест

`chi_square(reference, current, config=None)` сравнивает доли категорий в двух
независимых батчах с помощью критерия независимости Пирсона. Нулевая гипотеза:
распределение категорий не зависит от источника строки (`Reference` или
`Current`). Статистика имеет вид

\[
\chi^2 = \sum_{i,j}\frac{(O_{ij}-E_{ij})^2}{E_{ij}},
\]

где `O` — наблюдаемые частоты, а `E` — ожидаемые частоты при независимости.
Для таблицы размера `2 × k` число степеней свободы равно `k - 1`.

## Совместное пространство и пропуски

- Категории берутся из объединения непустых значений Reference и Current.
- Значения сравниваются с учётом Python-типа: число `1` и строка `"1"` не
  сливаются.
- `NaN`, `None` и `pd.NA` исключаются из χ²; изменение пропусков остаётся
  отдельным сигналом Data Quality.
- Исходные Series не изменяются.

## Политика редких категорий

В версии 0.1 используется детерминированное объединение редких категорий.
Категория считается редкой, если её суммарная частота в Reference и Current
меньше `10`; все такие значения объединяются в одну ячейку. После объединения:

1. должны остаться минимум две эффективные категории;
2. каждая наблюдаемая частота должна быть не меньше `5`;
3. каждая ожидаемая частота должна быть не меньше `5`.

Если хотя бы одно условие нарушено, метод возвращает `status="skipped"`,
`p_value=None` и объяснение. Это консервативная политика: она может пропустить
реальный сдвиг по новой редкой категории, зато система не выдаёт необоснованный
асимптотический p-value. Границы можно переопределить в локальном `config`
функции ключами `rare_category_min_total`, `min_observed_count` и
`min_expected_count`; общая конфигурация pipeline пока использует значения
версии 0.1.

Поправка Йейтса отключена (`correction=False`), поэтому рассчитывается обычная
статистика Пирсона для всех размеров таблицы.

## Интерпретация

Малое p-value означает: при нулевой гипотезе наблюдаемая или более сильная
разница частот маловероятна. Оно не равно вероятности того, что дрейфа нет, и
не показывает величину или бизнес-значимость изменения. Решение об алерте
принимается отдельно после поправки на множественные проверки.

В одном вызове `analyze` семейство для Benjamini–Hochberg состоит из всех
пригодных p-value KS и χ² по анализируемым признакам. Пропущенные и ошибочные
проверки в семейство не входят. Сохраняются исходное `p_value` и
`adjusted_p_value`; FDR-коррекция контролирует ожидаемую долю ложных открытий
среди отклонённых гипотез, а не вероятность ошибки каждой отдельной проверки.

Руководство SciPy указывает часто используемое условие о частотах не меньше 5:
<https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.chi2_contingency.html>.
